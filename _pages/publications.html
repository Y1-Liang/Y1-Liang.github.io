Look Carefully: Adaptive Visual Reinforcements in Multimodal Large Language Models for Hallucination Mitigation

Xingyu Zhu, Kesen Zhao, Liang Yi, Shuo Wang, Zhicai Wang, Beier Zhu, Hanwang Zhang, Xiangnan He

AIR is a training-free framework that combines prototype-based visual-token reduction with optimal-transport-guided patch reinforcement. It strengthens useful visual evidence while suppressing redundant information.

Adapting Point Cloud Analysis via Multimodal Bayesian Distribution Learning

Xingyu Zhu, Liang Yi, Shuo Wang, Wenbo Zhu, Yongliang Wu, Beier Zhu, Hanwang Zhang

BayesMM performs training-free test-time adaptation by modeling textual priors and streaming visual features as Gaussian distributions, then combining them through Bayesian model averaging.
