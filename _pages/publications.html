ICLR 2026

Look Carefully: Adaptive Visual Reinforcements in Multimodal Large Language Models for Hallucination Mitigation

Xingyu Zhu, Kesen Zhao, Liang Yi, Shuo Wang, Zhicai Wang, Beier Zhu, Hanwang Zhang, Xiangnan He

AIR is a training-free framework for mitigating hallucination in multimodal large language models. It combines prototype-based visual-token reduction with optimal-transport-guided patch reinforcement to strengthen useful visual evidence while suppressing redundant information.

CVPR 2026

Adapting Point Cloud Analysis via Multimodal Bayesian Distribution Learning

Xingyu Zhu, Liang Yi, Shuo Wang, Wenbo Zhu, Yongliang Wu, Beier Zhu, Hanwang Zhang

BayesMM performs training-free test-time adaptation for point cloud analysis by modeling textual priors and streaming visual features as Gaussian distributions and combining them through Bayesian model averaging.

CVF Open Access · arXiv
